# AGENTS.md

Claude Code sessions on the BUSY Bar: an app on the bar, a Claude Code plugin, and a local daemon that connects them.

## Layout

- `app/`: the bar app, id `app.mrlunev.claude_code`, TypeScript built with `busy-cli build`. Its own `package.json`,
  lock file, `catalog.json` (the catalog's texts), `screenshots/`, `LICENSE` and `README.md`. The BUSY Apps catalog
  builds from this folder (`subdir: app` in the catalog manifest).
  - `src/main.ts`: the whole app; `src/appmeta/` manifest, settings and icons; `src/images/`, `src/animations/`
    are generated by `tools/make-images.mjs` and `tools/pack.py` (`npm run images`).
  - `shared/device.ts`: a thin `fetch` client for the bar's API. The `BusyBar` client of busy-lib throws on the
    device (its timeout needs a working `AbortController`), so it is not used.
- `plugin/`: the Claude Code plugin `busybar`.
  - `.claude-plugin/plugin.json`: name and version (the plugin has its own version, separate from the app's).
  - `hooks/hooks.json`: `SessionStart` runs `daemon/claude-bar-daemon.mjs --ensure`; every event is posted to
    `http://127.0.0.1:8790/hook`.
  - `daemon/`: the local server, no dependencies, Node 20+. `claude-bar-daemon.mjs` serves the bar (`/state`,
    `/answer`) and Claude Code (`/hook`); `setup.mjs` finds the bar, installs the app, writes its settings and
    pairs them; `bar-api.mjs` and `mdns.mjs` talk to the bar and find it on Wi-Fi.
  - `skills/setup/`: the `/busybar:setup` skill.
  - `release/app.mrlunev.claude_code.tgz`: the built app that setup puts on the bar. Rebuilt by
    `npm run release` in `app/`.
- `.claude-plugin/marketplace.json`: the marketplace, one plugin from `./plugin`.
- `install.sh`, `install.ps1`: one-line installers for macOS and Windows (Node, the plugin, setup over USB).
- `README.md`: for people installing it; `media/`: its pictures.

## Build

```
cd app
npm ci
npm run typecheck
npm run build      # dist/app.mrlunev.claude_code.tgz
npm run release    # also writes ../plugin/release/app.mrlunev.claude_code.tgz
```

On exFAT (and other disks without extended attributes) macOS adds `._*` files and `busy-cli build` packs them, which
gives a truncated archive. Check every package with `tar -tzf dist/app.mrlunev.claude_code.tgz`; if it fails or lists
`._*`, build in a clone on an APFS disk with `COPYFILE_DISABLE=1`.

## Rules

- The daemon listens on port 8790. Don't start a second daemon or restart the running one on someone's machine
  without asking; tests use their own `--port`.
- The daemon's config and token live in `~/.config/busy-claude-bar`. The bar's app settings hold the token in clear:
  never print them.
- App version stays `0.1.0` until the app is published in the BUSY Apps catalog. A catalog update raises it in
  `app/src/appmeta/manifest.json` and `app/package.json` together.
- Changing the daemon's protocol: bump `API` in `app/src/main.ts` and `API_VERSION` in
  `plugin/daemon/claude-bar-daemon.mjs` together; the app shows "Update app" when the daemon is newer.
- Commits: author and committer `mrlunev <257361647+mrlunev@users.noreply.github.com>`; no AI mentions or
  `Co-Authored-By` lines. No middle dot as a separator in texts.
- Bar: check the serial (`GET /api/status/device`) before acting; never flash it; never call
  `POST /api/wifi/disconnect`; leave the bar as you found it.
